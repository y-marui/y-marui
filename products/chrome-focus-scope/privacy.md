# プライバシーポリシー（日本語正式版）

## 1. 提供者および提供形態

Focus Scope - Smart Website Blocker（以下「本拡張機能」）は、個人開発者により、無償で提供されるChrome拡張機能です。
本拡張機能の提供は事業として行われるものではありません。

## 2. 本拡張機能の概要

本拡張機能は、ユーザーが指定したウェブサイトへのアクセスを制限することにより、集中力の維持を支援するツールです。

## 3. 取得・収集する情報

本拡張機能は、以下の情報のみを取り扱います。

- ユーザーが設定したブロック対象URL
- ブロックの動作設定（モード、時間帯等）
- 拡張機能の動作に必要な最小限の設定情報

本拡張機能は、以下の情報を収集しません。

- 氏名、メールアドレス等の個人情報
- パスワード、認証情報
- 閲覧履歴
- 閲覧内容の外部送信
- 外部サーバーへのデータ送信

## 4. 情報の保存方法

設定情報は、以下の方法で保存されます。

- chrome.storage.local（ユーザーのブラウザ内へのローカル保存）
- chrome.storage.sync（同一GoogleアカウントでログインしているChrome間での同期）

本拡張機能は、外部サーバーへの通信によるデータ保存を行いません。

## 5. 第三者提供

本拡張機能は、ユーザー情報を第三者に販売、共有、提供することはありません。

## 6. 権限の利用目的

本拡張機能は、ユーザーが指定したURLとの一致判定およびアクセス制御のために必要最小限の権限のみを使用します。
取得した情報は、ブロック機能の実現以外の目的では使用されません。

## 7. 免責事項

本拡張機能は、現状有姿（As Is）で提供されます。

開発者は、本拡張機能の正確性、完全性、継続性、特定目的適合性を一切保証しません。

本拡張機能の利用または利用不能により生じた一切の損害について、開発者は責任を負いません。
これには、データ損失、業務上の損失、逸失利益、誤作動、意図しないブロックまたは非ブロックを含みますが、これらに限定されません。

開発者の損害賠償責任が法令上否定できない場合であっても、その賠償額の上限は0円とします。

## 8. 改定

本ポリシーは、必要に応じて改定されることがあります。
改定後の内容は、Chrome Web Store 上に掲載された時点で効力を生じます。

## 9. 準拠法および管轄

本ポリシーは日本法に準拠します。
本拡張機能に関して紛争が生じた場合は、日本の裁判所を専属的合意管轄とします。

# Privacy Policy (English Translation – Reference Only)

## 1. Provider and Nature of Service

Focus Scope - Smart Website Blocker (the “Extension”) is developed and provided by an individual developer, free of charge.
It is not provided as a commercial business.

## 2. Overview

The Extension helps users maintain focus by restricting access to user-defined websites.

## 3. Information Processed

The Extension processes only:

- User-defined blocked URLs
- Blocking settings (such as mode and schedule)
- Minimal configuration data required for functionality

The Extension does NOT collect:

- Personal information (such as name or email address)
- Passwords or authentication data
- Browsing history
- Page content
- Any data transmitted to external servers

## 4. Data Storage

Settings are stored using:

- chrome.storage.local (local browser storage)
- chrome.storage.sync (synchronization across Chrome browsers signed in with the same Google account)

No external server storage is used.

## 5. Third-Party Sharing

No user data is sold, shared, or provided to third parties.

To the maximum extent permitted by law, the maximum liability of the developer shall be zero (0) yen.
