# プライバシーポリシー（日本語正式版）

## 1. 提供者およびサービス概要

Focus Scope - Smart Website Blocker（以下「本拡張機能」）は、個人開発者により、無償で提供されるChrome拡張機能です。

本拡張機能は、ユーザーが指定したウェブサイトへのアクセスを制限することにより、集中力の維持を支援するツールです。

## 2. 取得・処理する情報

本拡張機能は、以下の情報のみを取り扱います。

- ユーザーが設定したブロック対象URL
- ブロックの動作設定（モード、時間帯等）
- 拡張機能の動作に必要な最小限の設定情報
- ブロック判定に必要な現在のタブのURLおよびナビゲーション情報

本拡張機能は、以下の情報を収集しません。

- 氏名、メールアドレス等の個人情報
- パスワード、認証情報
- 閲覧履歴
- 閲覧内容の外部送信
- 外部サーバーへのデータ送信

## 3. 利用目的

処理する情報は、ユーザーが指定したウェブサイトへのアクセスを制限し、集中作業を支援する機能のためだけに使用します。

## 4. 保存方法

設定情報は、以下の方法で保存されます。

- chrome.storage.local（ユーザーのブラウザ内へのローカル保存）
- chrome.storage.sync（同一GoogleアカウントでログインしているChrome間での同期）

本拡張機能は、外部サーバーへの通信によるデータ保存を行いません。

chrome.storage.sync に保存される設定情報は、同一の Google アカウントでログインしている Chrome 間で同期されます。開発者がこれらの設定情報を受け取ることはありません。

## 5. 外部送信および第三者提供

本拡張機能は、ユーザー情報を第三者に販売、共有、提供することはありません。

## 6. 権限およびAPIの利用

本拡張機能は、ユーザーが指定したURLとの一致判定およびアクセス制御のために必要最小限の権限のみを使用します。
取得した情報は、ブロック機能の実現以外の目的では使用されません。

## 7. 改定

本ポリシーは、必要に応じて改定されることがあります。
改定後の内容は、本ページに掲載された時点で効力を生じます。

# Privacy Policy (English Translation – Reference Only)

## 1. Provider and Service Overview

Focus Scope - Smart Website Blocker (the “Extension”) is developed and provided by an individual developer, free of charge.
The Extension helps users maintain focus by restricting access to user-defined websites.

## 2. Data Processed

The Extension processes only:

- User-defined blocked URLs
- Blocking settings (such as mode and schedule)
- Minimal configuration data required for functionality
- The current tab URL and navigation information needed to determine whether to block access

The Extension does NOT collect:

- Personal information (such as name or email address)
- Passwords or authentication data
- Browsing history
- Page content
- Any data transmitted to external servers

## 3. Purpose of Use

The processed information is used only to restrict access to user-defined websites and provide focus-support features.

## 4. Storage

Settings are stored using:

- chrome.storage.local (local browser storage)
- chrome.storage.sync (synchronization across Chrome browsers signed in with the same Google account)

No external server storage is used.

Settings stored with chrome.storage.sync are synchronized between Chrome browsers signed in with the same Google account. The developer does not receive these settings.

## 5. External Transmission and Third-Party Sharing

No user data is sold, shared, or provided to third parties.

## 6. Permissions and APIs

The Extension uses only the permissions necessary to match user-defined URLs and control access to those URLs. Information processed through these permissions is not used for any other purpose.

## 7. Changes to Policy

This policy may be revised as necessary. Revised content takes effect when published on this page.
