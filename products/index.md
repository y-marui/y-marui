# Products

## Browser Extensions

### [Zotero Library Checker - Duplicate Reference Detection](chrome-library-check-for-zotero/)

現在閲覧している論文が、ローカルの Zotero ライブラリにすでに登録されているかをすぐに確認します。文献の重複登録を防ぐためのツールです。

- [Chrome Web Store](https://chromewebstore.google.com/detail/zotero-library-checker/njakhbdjddaflodiogjmbledldjjbbai)
- [Firefox Add-ons](https://addons.mozilla.org/ja/firefox/addon/library-check-for-zotero/)

### [Focus Scope - Smart Website Blocker](chrome-focus-scope/)

SNSや時間を奪うサイトをブロックします。スプリントや曜日・時間帯のスケジュールで集中を保つためのサイトブロッカーです。

- [Chrome Web Store](https://chromewebstore.google.com/detail/focus-scope-smart-website/dnpccglkhnnlogdolajjhehicbegnlcg)
- [Firefox Add-ons](https://addons.mozilla.org/ja/firefox/addon/focus-scope/)

## Google Workspace Add-ons

### [Log Pair](gwa-log-pair/)

Google カレンダーの打刻イベント（入退勤など）をペアで統合する Google Workspace Add-on です。

### Browser Extensions

#### [Zotero Library Checker - Duplicate Reference Detection](chrome-library-check-for-zotero/)

Check instantly whether the paper you're viewing is already saved in Zotero. A simple tool to prevent duplicate saves.

Block SNS and time-wasting sites. A site blocker to keep your focus going with sprints and day-of-week schedules.

- [Chrome Web Store](https://chromewebstore.google.com/detail/focus-scope-smart-website/dnpccglkhnnlogdolajjhehicbegnlcg)

### Google Workspace Add-ons

#### [Log Pair](gwa-log-pair/)

Google Workspace Add-on that merges paired calendar events, such as clock-in and clock-out events.
