# Preprint Publish Tracker

Register the preprints you follow (arXiv, bioRxiv, medRxiv, Research Square, TechRxiv and others) and get an email when one is published as a journal article with a DOI.

プレプリント（arXiv、bioRxiv、medRxiv、Research Square、TechRxiv など）を登録しておくと、正式な論文として出版され DOI が付与されたときにメールでお知らせする Web アプリです。

## Access

The service is invitation only and is limited to people with an `.ac.jp` email address. There is no public sign-up. The [front page](https://preprint-lan.ymarui.com/top) explains how it works and is readable without an account.

招待制で、`.ac.jp` のメールアドレスをお持ちの方に限ります。一般の登録受付はありません。[トップページ](https://preprint-lan.ymarui.com/top)は、アカウントがなくても読めます。

## Source code

The application is open source: [y-marui/python-preprint-publish-tracker](https://github.com/y-marui/python-preprint-publish-tracker).
