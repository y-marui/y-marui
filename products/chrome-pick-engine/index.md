# Pick Engine

Splits your address-bar search across the search engines you choose, with no external relay. Searches are routed by weighted random pick, and you can define named groups of engines and select one with a `mode` parameter.

## Install

[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/ihcfdhceinllkcdopimkbofloecbgdgc).
