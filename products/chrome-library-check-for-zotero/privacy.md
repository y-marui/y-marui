# プライバシーポリシー（日本語正式版）

## 1. 提供者およびサービス概要

Zotero Library Checker - Duplicate Reference Detection（以下「本拡張」）は、個人開発者により無償で提供されるブラウザ拡張機能です。
本拡張は、ユーザーが閲覧している論文ページの情報を基に、当該論文がローカル環境のZoteroライブラリに登録されているかを確認するための補助ツールです。

本拡張は、ユーザーのコンピュータ上で動作するZoteroアプリケーション（localhost:23119）とのみ通信します。

## 2. 取得・処理する情報

本拡張は、機能提供のために、現在閲覧中のページのURLおよび論文のメタデータ、ローカルZoteroライブラリへの照会結果、ユーザー設定を端末上で処理します。
本拡張は、個人情報を開発者のサーバーに収集・送信・保存しません。

・ユーザーデータを開発者のサーバーへ送信することはありません
・第三者サーバーとの通信は行いません
・外部解析ツールや広告サービスは使用していません
・ユーザーの閲覧履歴を収集・保存しません

## 3. 利用目的

処理した情報は、閲覧中のページが論文ページかを判定し、対応する文献がローカルZoteroライブラリに登録済みかを確認して表示するためだけに使用します。

## 4. 保存方法

設定情報等は、Chromeのstorage APIを用いてユーザーの端末内にのみ保存されます。

## 5. 外部送信および第三者提供

本拡張は、ZoteroローカルAPI（localhost）とのみ通信します。
インターネット上の外部サーバーに論文情報や閲覧情報を送信することはありません。

## 6. 権限およびAPIの利用

現在のタブのURLおよびページ情報は、論文ページの検出とローカルZoteroライブラリの照会のためにのみ使用します。Zoteroとの通信先は、ユーザーの端末上で動作する localhost:23119 または 127.0.0.1:23119 に限定されます。

## 7. 改定

本ポリシーは、必要に応じて改定されることがあります。改定後の内容は本ページに掲載された時点で効力を生じます。

# Privacy Policy (English Translation – Reference Only)

## 1. Provider and Service Overview

Zotero Library Checker - Duplicate Reference Detection (the “Extension”) is a free browser extension provided by an individual developer.
The Extension checks whether a paper currently viewed in the browser is already registered in the user’s local Zotero library.

The Extension communicates only with the Zotero application running locally on the user’s computer (localhost:23119).

## 2. Data Processed

To provide its functionality, the Extension processes the current page URL and paper metadata, local Zotero library query results, and user preferences on the user’s device.
The Extension does not collect, transmit, or store personal data on the developer’s servers.

• No data is sent to the developer’s servers
• No third-party servers are contacted
• No analytics or advertising services are used
• The Extension does not collect or store users’ browsing history

## 3. Purpose of Use

The processed information is used only to identify whether the current page is a paper page and to check and display whether the corresponding paper is already saved in the local Zotero library.

## 4. Storage

User preferences are stored locally using Chrome’s storage API.

## 5. External Transmission and Third-Party Sharing

Paper metadata and browsing information are not transmitted to any external internet server.

## 6. Permissions and APIs

The current tab URL and page information are used only to detect paper pages and query the local Zotero library. Communication with Zotero is limited to localhost:23119 or 127.0.0.1:23119 on the user’s device.

## 7. Changes to Policy

This policy may be revised as necessary. Revised content takes effect when published on this page.
